# claw

A personal always-on assistant built on Claude Code: one long-running hub session with
Remote Control, a global skill pack, and per-domain scripts. See `CLAUDE.md` for the router.

Start it: `~/claw/bin/claw-start` (then message it from the Claude app or claude.ai/code).

Skills come from the `claw` marketplace (`~/projects/claw-skills`).
